About

Spikedex is an unofficial, fan-made, non-commercial library of the character skins created by the just volleyball community.

What you can do here

  • Browse skins and search by name, author or category.
  • View each skin in 3D, running the game's own character code in your browser.
  • Copy the skin code (JV2:…) and import it in the game's own import screen.
  • Download the skin card, the same image the game generates.

Where the skins come from

Skins are shared publicly by their authors in the game's community Discord. Each skin is shown with credit to its author's public Discord username. Authors can ask for their skins, or their username, to be removed at any time: see removal requests.

The skins listed today were collected from that Discord. Soon the site will launch uploads, so authors can publish their skins here directly, and that will become the main way skins arrive.
